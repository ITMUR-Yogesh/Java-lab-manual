## How to Use

1. Open a practical folder from the table above.
2. Read its `README.md` for the question, concepts, and run instructions.
3. Open the `.java` source file(s).
4. Run the program in IntelliJ IDEA or another Java IDE.
5. The corresponding output screenshot is included in the same practical folder.

## Output Images

The screenshots are stored **inside each practical folder** so GitHub can display them directly from the README. For example:

```md
![Practical 01 Output](out.png)
```

For Practical 04 and Practical 06, there are separate server/client screenshots. For Practical 12, there are separate Create/Update screenshots.
